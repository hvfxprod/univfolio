# Seoul Institute of the Arts logo

Original PNG from the university's official portal (downloaded 2026-10-04):
https://sportal.seoularts.ac.kr/resources/custom/images/main/login-brand.png

Source page: https://sportal.seoularts.ac.kr/login/find/id
Symbol reference: https://www.seoularts.ac.kr/web/content.do?proFn=9131000

The original PNG is unchanged. UniversityBrand displays the red symbol using
an overflow viewport; the white wordmark is outside that viewport. The English
name is rendered separately as accessible text for light backgrounds.
